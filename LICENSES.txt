LICENSE CHECK PROCEDURE
================================================================================

To verify licenses for a release:

1. Check Rust dependencies:
   ```bash
   cargo license --json > licenses.json
   # Verify no GPL, AGPL, SSPL
   ```

2. Check npm dependencies:
   ```bash
   npm audit --production
   npm ls --production | grep "LICENSE"
   ```

3. Check bundled models:
   - Confirm model license in distribution
   - Document model source and license in release notes

4. Update this file:
   - Before major release (v1.0.0)
   - When adding new dependency
   - When upgrading major version of dependency
